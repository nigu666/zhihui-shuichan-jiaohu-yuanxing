# 智慧水产交互原型作品集

作者：雷雨天

## 简介

该仓库用于整理本人实习期间参与制作和迭代的智慧水产相关交互原型。

本人主要负责的工作集中在：

- 移动端交互原型搭建
- Vue2 页面迁移与适配
- Dify 可视化 AI 助手原型搭建
- Web 管理端原型迁移与交互调整
- 根据已有业务逻辑进行页面功能理解与修改
- 数字孪生页面快速交互原型设计
- 根据需求持续进行界面和交互迭代
- 配合团队进行原型验证与方案确认

## 项目价值

这些原型主要用于：

- 帮助团队快速确认页面需求和交互方案
- 降低从需求描述到可视化页面之间的沟通成本
- 为后续正式前端开发和页面迁移提供参考
- 通过可交互原型更直观地验证业务流程和界面设计
- 通过 Dify 可视化方式快速验证 AI 助手在智慧水产场景中的交互形式

## 工作范围说明

本人不涉及：

- 后端系统开发
- 数据库设计
- 正式生产环境部署
- 底层大模型训练
- 服务端接口开发
- 正式系统架构设计
