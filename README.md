## 主案例

### 智慧增殖站 · 2026.08—09

- 参加导师、甲方与养殖专家的三方会谈，记录结论。专家指出现场投喂计量和填报负担，导师提出替代方案，我据此修改投喂模块原型，方案进入开发阶段。
- 梳理 33 份运行资料，将 17 份纳入核心业务、10 份并入现有流程、6 份留在本期范围之外。
- 发现维修工单与经验库的流转状态不同步，亲自验证提交、驳回、重新提交和审核结果回填。原型用工单 ID 关联记录。

### 智慧水产 AI 助手 · 2026.07—08

- 梳理养殖问答、设备查询和水质分析场景，参与 Dify 工作流配置、业务接口联调及移动端对话原型设计。
- 测试“检测水质”触发的池体编号追问。作品集同时展示成功查询和未匹配到设备的历史运行截图。
