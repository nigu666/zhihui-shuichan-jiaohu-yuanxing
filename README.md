## 首页结构与技术

首页采用“项目协作档案”方向：白底、蓝色强调、四条开放式编号索引，以及与档案 04 明确关联的数据驾驶舱主图。手机先展示四个项目索引，再展示驾驶舱画面。四个完整案例分别说明业务背景、我负责、协作与迭代过程、项目价值及原型入口。

首页仅使用 HTML、内联 CSS 和轻量原生 JavaScript，不增加构建工具、依赖、后端接口或 AI 服务。截图使用原生 `dialog` 查看器，支持关闭、上一张/下一张、Escape、左右方向键、焦点循环和返回触发按钮；按钮与关键操作支持键盘聚焦和减少动态效果设置。

四个正式原型及其资源沿用原始项目，没有因首页改版修改。首页的驾驶舱和数字孪生图片直接引用本仓库已有资源；移动端与 Dify 截图通过相对路径引用相邻的 `ai-application-engineer-portfolio/assets/`。两个 GitHub Pages 项目位于相同账户的同一父级地址，因此与本地并排目录保持一致。

## 原型与服务边界

- 首页展示真实职责和既有项目画面，不宣称生产系统交付或业务规模。
- 数字孪生场景使用原项目既有素材，不代表本人独立制作三维模型。
- 原型中的数据和交互用于展示方案，不作为实时生产数据、模型效果或业务成效证明。
- 移动端 AI 服务不可用时会展示网络异常。对话空屏与异常反馈不作为成功调用 AI 的证据。
- 打开原型在独立页面查看，不在首页用整页嵌入代替项目说明。
