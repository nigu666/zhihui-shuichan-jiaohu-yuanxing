## 关于这个作品集

该仓库整理了本人实习期间参与制作和持续迭代的智慧水产相关交互原型。

本人工作主要集中在：

- 需求理解与页面拆解
- 移动端和 Web 交互原型
- Vue2 页面迁移与适配
- Dify AI 助手原型验证
- 数字孪生页面快速设计
- 根据需求和反馈持续进行界面迭代

## 我在项目中的角色

我参与的主要是产品原型和前端交互这一部分。

在智慧水产移动端中，我负责页面原型搭建，并配合现有 Vue2 项目进行页面迁移和适配；AI 助手部分主要通过 Dify 的可视化方式进行搭建和效果验证。

在智慧增殖站 Web 和数字孪生相关工作中，我的主要任务是在理解实际业务逻辑以后，快速把需求做成可以直接操作的交互原型，再根据反馈持续修改页面和交互。

作品集主要展示的是这些原型设计和验证工作，不代表本人负责了完整后端、数据库或生产系统开发。
